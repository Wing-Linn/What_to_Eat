# 今天吃什么 · 盲盒抽取

> 把选择交给今天的好运气。

一款帮助解决"今天吃什么"选择困难的轻量 Web 应用。设置用餐时段、预算、口味、菜系和忌口，点击"开始抽盲盒"，从符合硬性条件的本地食物候选库中随机抽出一个结果，配合盲盒摇晃揭晓动画和推荐理由。可选接入 AI，实现自然语言偏好解析（"想吃热乎的，不要辣，30 元以内"）和个性化推荐理由生成。

## 功能特性

### 核心抽取（无需 AI 即可完整使用）

- **用餐时段**：早餐 / 午餐 / 晚餐 / 夜宵 / 不限，打开页面时按本地时间自动默认，可手动修改
- **快捷偏好**：预算（不限 / 15 / 30 / 50 元以内）、菜系（中式、川湘、粤菜、日料、韩餐、西餐、轻食、面食等 10 类）、口味（清淡 / 微辣 / 重辣 / 酸甜 / 咸香 / 随便）
- **更多条件**（可折叠面板）：食物类型、用餐方式（堂食 / 外卖 / 自己做）、过敏原排除、忌口食材、自定义排除词（如香菜、动物内脏）
- **硬性条件优先**：预算上限、过敏原、忌口属于硬性限制，任何情况下不会被自动放宽；价格未知的食物不会被纳入预算过滤；过敏原信息未知的食物不会被标记为"安全"
- **加权随机**：先按硬性条件过滤，再按软性偏好（菜系 +3、口味 +3、类型 +2、方式 +2、心情标签 +1）计算匹配分形成权重，最终结果仍带随机性，避免永远固定为同一项
- **盲盒动画**：抽取时盲盒摇晃，揭晓时缩放淡入；动画期间防重复点击；支持系统级"减少动态效果"偏好
- **三选一模式**：一次抽出三个不同候选供挑选，候选不足时只展示实际数量
- **空状态引导**：无结果时列出可能过严的条件，提供"放宽预算 / 清除普通偏好 / 扩大时段"快捷按钮（过敏原和忌口不会自动放宽，需手动调整）

### 反馈与记录

- **收藏**：抽到喜欢的可以"先收藏起来"，收藏页随时查看和取消
- **反馈**：喜欢 / 不喜欢评价
- **采纳**：点"今天就吃这个"表示采纳灵感，不代表已实际购买；历史记录中可再标记"实际吃了 / 没吃"
- **吃饭记录**：按时间倒序展示抽取历史，支持按已采纳 / 喜欢 / 不喜欢筛选，附简单统计（总抽取数、采纳率、喜欢、不喜欢）

### AI 增强（可选）

- **自然语言偏好解析**：一句话描述需求，AI 自动回填预算、口味、菜系、忌口等偏好
- **推荐理由生成**：根据食物真实数据和你当前的偏好，生成 20–50 字的推荐理由
- **自动降级**：AI 未配置、超时或返回异常时，自动切换为本地推荐理由模板，抽取主流程完全不受影响，并在结果卡片上提示"AI 暂时不可用"

### 数据存储

- 食物候选库内置在前端代码中（88 条，覆盖四个时段、多种菜系和价格区间）
- 收藏和历史记录保存在云端数据库（Supabase），刷新页面、更换设备都不丢失
- 偏好设置保存在浏览器本地，读取失败时自动恢复默认值，不会白屏

## 技术栈

- React 18 + TypeScript + Vite
- Tailwind CSS（自定义薄荷绿主题色，米白背景，柔和阴影）
- Zustand（状态管理）
- Supabase（收藏与历史云端持久化，含行级安全策略）
- Supabase Edge Functions（AI 服务端代理，密钥只存在服务端）
- Lucide React（线性图标）

## AI 配置方法

AI 走服务端代理，密钥不会出现在前端代码中。需要在大模型服务商处获取 API Key 后，将其配置为 Supabase 项目的边缘函数密钥（环境变量名以服务端代码为准）：

- `LLM_API_KEY`：大模型服务商的 API Key
- `LLM_BASE_URL`：兼容 OpenAI Chat Completions 协议的接口地址
- `LLM_MODEL`：模型名称

配置方式：在 Supabase 控制台的 Edge Functions 密钥管理中添加以上三个密钥，AI 功能即自动启用。**未配置或服务异常时应用仍可完整使用**——抽取、筛选、收藏、记录均正常，仅智能解析和 AI 推荐理由切换为本地降级模式。

AI 的职责边界（按需求文档约束）：

1. 只负责把自然语言转成结构化偏好、根据真实数据生成推荐理由
2. 不决定最终抽取结果，不新增食物候选
3. 不能覆盖忌口、过敏原和预算等硬性限制
4. 不编造价格、食材、营养和健康结论
5. 模型输出经过服务端校验和长度限制，异常时走降级

## 设计说明

- **视觉**：简约清新风——柔和米白背景、薄荷绿主色、浅橙点缀、白色圆角卡片配轻阴影，系统无衬线中文字体栈
- **响应式**：手机端单列布局、大号可点按钮、标签自动换行；桌面端内容居中（最大约 672px），主要操作触手可及
- **无障碍**：所有多选按钮带 `aria-pressed` 状态，键盘焦点清晰可见，动效支持 `prefers-reduced-motion`

## 数据安全约定

- 未知价格不能宣称符合预算；未知过敏原不能视为安全
- 候选不足时不会忽略明确的排除条件
- 结果卡片标注"具体价格和食材以实际店铺为准"
- 收藏与历史表已启用行级安全（RLS），按最小权限授予访问
